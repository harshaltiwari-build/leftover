# Leftover v0.8.2

Leftover has a website: **[harshaltiwari-build.github.io/leftover](https://harshaltiwari-build.github.io/leftover/)**. It shows what the app does, screenshots in light and dark, and always links to the latest download.

## Changed
- **Settings → About Leftover** links to the website. Tapping it opens your browser; Leftover itself still never goes online.
- About lists all three bundled fonts (Manrope, Bricolage Grotesque, Plus Jakarta Sans).

## Tested
407 unit, integration and journey tests pass on the computer, and all 26 journeys pass on a Motorola Edge 40 Neo (Android 15).

## Install
Download `leftover-0.8.2.apk` and open it on your phone, or get it from the website. Same debug key as earlier versions, so it installs over v0.8.1 and keeps your data. ARM phones only.
