# Leftover v0.9.1

## Fixed
- **The bell on Home** opened the Plan page. It now opens your reminder settings (bills due, payday, budgets, weekly check-in), and still shows a dot when a bill is due within two days.

## Tested
494 unit, integration and journey tests pass on the computer, including a new journey for the bell. The signed APK was installed over v0.9.0 on a Motorola Edge 40 Neo (Android 15) and keeps your data.

## Install
Download `leftover-0.9.1.apk` and open it, or use **Settings → About Leftover → Check for updates** if you turned updates on. Same release key as v0.9.0, so it installs over it and keeps your data.
