# Leftover v0.8.1

Fixes from testing a fresh install of v0.8.0 on a phone.

## Changed
- **Portrait only.** Leftover stays upright. Turned sideways, the welcome screen's buttons ran off the bottom.
- **The tab bar is a solid card again**, with icons and a whole, raised + button.

## Fixed
- During setup, tapping Edit on a bill opened its editor below the fold, hidden behind the summary. It now scrolls into view.
- With no name set, Home's avatar showed "T" (from "there"). It now shows a person.

## Tested
405 unit, integration and journey tests pass on the computer, and all 25 journeys pass on a Motorola Edge 40 Neo (Android 15).

## Install
Download `leftover-0.8.1.apk` and open it on your phone. Same debug key as earlier versions, so it installs over v0.8.0 and keeps your data. ARM phones only.
