# Leftover v0.9.0

## New
- **Payment screenshots ask first.** Share a PhonePe, Google Pay or Paytm screenshot and Leftover reads the amount, who you paid, the date and the app, fills everything in, and shows it for you to check. You can change the account, category or any field, then tap Add. It warns about duplicates, old or large payments, and missing payee names.
- **Update from inside the app (optional).** Settings → About Leftover can check for a new version, download it, and hand it to Android to install. It is off until you turn it on or tap "Check now". Only the version information is requested from GitHub; nothing about you is sent. The download must come from GitHub over HTTPS, match its published SHA-256, and be signed by the same key as the app you have installed.
- **Reminders arrive on time.** Daily and one-off reminders now use clock alarms with a backup, and are re-armed after a restart.
- **Quick add** fits everything on one screen with the rows lined up.

## Changed
- Leftover now asks Android for two permissions, both only for updates: internet, and installing the downloaded update. Everything else still works fully offline.
- The payment-screenshot reader is more accurate on real receipts (₹ read as `*`, wrong app name, missing amounts) and no longer hangs on huge or malicious text.

## Important: install note
This is the first release signed with a private release key, not the old debug key. Android will not install it over v0.8.2. **Back up first (Backup screen), uninstall the old Leftover once, then install this.** Future updates, including in-app ones, will install over it and keep your data.
